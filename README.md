# Eldridge Baseball Dugout historical archive

This repository distributes optional historical baseball data for Eldridge Baseball Dugout. The application source is maintained separately and is not included here.

The initial release contains a compressed SQLite baseline. Later releases contain incremental data packs and an `archive.json` manifest declaring their required base and result hashes. Use the application's Baseball Library update controls to install them. Keep the baseline and intermediate releases available for new installations and users catching up.

Archives are prepared locally and uploaded by the maintainer as drafts. Published releases are immutable; corrections receive new versions. GitHub Actions is disabled. Public access allows downloads and forks, not write or release-publishing access.

Coverage varies by year and source. Missing figures, reconstructed accounts, alternative statistical interpretations and source discrepancies remain preserved. Historical records are separate from simulated leagues and modeled player ratings.
